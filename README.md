## Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/askhan-cloud27/cloud-aws-portfolio.git
   ```

2. Open the project folder:

   ```bash
   cd cloud-aws-portfolio
   ```

3. Open `index.html` in your browser.

No additional packages or paid services are required to run this static website locally.
