# Cloud & DevOps Learning Roadmap

## Phase 1 — Portfolio Foundations
- [x] Build a static portfolio using HTML, CSS, and JavaScript
- [x] Initialize Git and publish the repository on GitHub
- [x] Create project documentation with README.md

## Phase 2 — Portfolio Improvements
- [ ] Improve responsive design and accessibility
- [ ] Add detailed project documentation
- [ ] Publish the website using GitHub Pages

## Phase 3 — Cloud Fundamentals
- [ ] Practice AWS IAM and security fundamentals
- [ ] Study VPC, networking, EC2, and S3
- [ ] Create architecture diagrams for learning projects

## Phase 4 — DevOps Foundations
- [ ] Practice Linux commands and shell scripting
- [ ] Learn Docker and container fundamentals
- [ ] Explore CI/CD and Infrastructure as Code

## Phase 5 — Practical Projects
- [ ] Build and document a practical cloud-related project
- [ ] Record architecture, challenges, and lessons learned
- [ ] Review security and possible costs before any cloud deployment

## Working Principles
- Prefer free learning resources and local development.
- Check possible cloud charges before creating resources.
- Never publish passwords, credentials, or other secrets.
- Mark tasks complete only after verifying them.
